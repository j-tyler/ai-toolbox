# ai-toolbox

A workspace for AI development tools, skills, and ideas.

## Ideas

- **[Change Intent](ideas/change-intent/README.md)** — a structured artifact authored before any code is written, capturing *why* a change is being made and *what falsifiable claims* the implementation must prove. The goal is to construct changes in a way that they're reviewable: less focus on the change itself, more focus on the review process around it.
